# Buggie v0.7.0

**小星星会飘、会用光赶走修好的虫子，还会飞升**

## 新功能

- **小星星飘起来了**:它收起小腿飘在地面上方，移动时身后留下一串星光。
- **用光代替吃虫**:修好一个 bug 时，小星星停在不远处朝虫子射出三道光，有的虫子跑出屏幕，有的被烧掉。
- **眨眼**:眨眼时眼角迸出一把小星星。
- **飞升**:新动作，笔直向上飘升，身后留下一串星光，再落回来。
