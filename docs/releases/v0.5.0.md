# Buggie v0.5.0

**Coo 改名为 Buggie,成了给开发者的编程助手:构建报错变成屏幕上的虫子，团队可以共用工单，在 Telegram 上也能和 Buggie 说话**

## 新功能

- **Buggie**:新的名字、形象和标志。Buggie 是陪你写代码的助手：帮你读代码、写代码、查错。
- **报错变成虫子**:用 `buggie-watch -- <命令>` 运行构建或测试，每个报错是地面上一只瓢虫;点一只，Buggie 解释哪里出错、怎么修。修好后 Buggie 把虫子吃掉。复制一段报错或堆栈时，头顶会问要不要解释。
- **GitHub**:打开后,Actions 失败的步骤也变成虫子;拉取请求和议题上的新通知由 Buggie 转告。
- **工具箱**:悬停按钮里的工具箱处理剪贴板里的文字：格式化 JSON、Base64、JWT、时间戳、URL 编解码、SHA-256、UUID。
- **专注**:悬停按钮开始一段专注，结束后提醒你休息。
- **团队服务器**:同一家公司的 Buggie 共用公司、工作组、项目和工单。工单派给你、你的工作组来了新工单、你的工单有修改或评论时,Buggie 告诉你。开工单时 Buggie 会询问还缺的细节：应该怎样、重现步骤、怎样算修好。在设置窗口的「团队」页登录;服务器的部署见 `team-server/README.md`。
- **Telegram**:在设置窗口的「Telegram」页连接自己的机器人，或公司在团队服务器上的机器人。在 Telegram 上发给 Buggie 的就是指令，它直接去做，并在那边回答;要你选择或确认的事也发到 Telegram,回复选项编号即可。公司的机器人还能在 Buggie 没连上时把工单动态发给你。

## 下载

- Windows x64 安装版:`Buggie-Setup-0.5.0.exe`
- Windows x64 便携版:`Buggie-0.5.0-win-x64-portable.zip`
- Apple 芯片 Mac:`Buggie-0.5.0-mac-arm64.dmg` / `.zip`
- Intel Mac:`Buggie-0.5.0-mac-x64.dmg` / `.zip`
- Linux x64:`Buggie-0.5.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:八个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 安装版和 AppImage 会自动更新到以后的版本。macOS 版本是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
