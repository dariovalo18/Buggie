# Buggie v0.6.0

**A new figure: the Little Star**

## New

- **Little Star**: a puffy five-pointed star with its face in the middle and two short legs, in gold, pink, sky blue, mint or night violet. Pick it in the **Figure** row of the Dress up page. Like Buggie, it walks, sits, sleeps and makes every face, and it chases and eats a bug when one is fixed.

## Download

- Windows x64 installer: `Buggie-Setup-0.6.0.exe`
- Windows x64 portable: `Buggie-0.6.0-win-x64-portable.zip`
- Apple silicon Mac: `Buggie-0.6.0-mac-arm64.dmg` / `.zip`
- Intel Mac: `Buggie-0.6.0-mac-x64.dmg` / `.zip`
- Linux x64: `Buggie-0.6.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`: SHA-256 checksums of the eight installer files.
- `latest.yml`, `latest-linux.yml`: version info for automatic updates; no need to download.

The Windows installer and the AppImage update themselves to this version. The macOS version is signed ad hoc and not notarized by Apple; the README says how to open it the first time. Translations other than Simplified Chinese and English are machine-made; PRs that fix them are welcome.
