# Buggie v0.6.0

**新形象「小星星」**

## 新功能

- **小星星**:一颗圆鼓鼓的五角星，脸在正中，两条短腿，有金色、粉色、天蓝、薄荷绿、夜紫五种配色。在装扮页的「形象」一行选择。它和 Buggie 一样会走、坐、睡、做各种表情，修好 bug 时也会追着虫子吃掉。

## 下载

- Windows x64 安装版:`Buggie-Setup-0.6.0.exe`
- Windows x64 便携版:`Buggie-0.6.0-win-x64-portable.zip`
- Apple 芯片 Mac:`Buggie-0.6.0-mac-arm64.dmg` / `.zip`
- Intel Mac:`Buggie-0.6.0-mac-x64.dmg` / `.zip`
- Linux x64:`Buggie-0.6.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`:八个安装文件的 SHA-256 校验值。
- `latest.yml`、`latest-linux.yml`:自动更新读的版本信息，不用下载。

Windows 安装版和 AppImage 会自动更新到这个版本。macOS 版本是临时签名、未经 Apple 公证，第一次打开的方法见 README。除简体中文和英文外的译文由模型翻译，欢迎提 PR 修正。
