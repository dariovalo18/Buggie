# Buggie v0.7.0

**The Little Star floats, shoots lights at fixed bugs, and soars**

## New

- **The Little Star floats**: it tucks its legs away and hovers over the floor, leaving a trail of sparkles as it moves.
- **Lights instead of eating**: when a bug is fixed, the Little Star stops a little way off and casts three lights at it. Some bugs run off the screen, others burn up.
- **Wink**: when it winks, a burst of little stars flies out of its eye.
- **Soar**: a new move that takes it straight up, leaving a column of sparkles under it, and brings it back down.

## Download

- Windows x64 installer: `Buggie-Setup-0.7.0.exe`
- Windows x64 portable: `Buggie-0.7.0-win-x64-portable.zip`
- Apple silicon Mac: `Buggie-0.7.0-mac-arm64.dmg` / `.zip`
- Intel Mac: `Buggie-0.7.0-mac-x64.dmg` / `.zip`
- Linux x64: `Buggie-0.7.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`: SHA-256 checksums of the eight installer files.
- `latest.yml`, `latest-linux.yml`: version info for automatic updates; no need to download.

The Windows installer and the AppImage update themselves to this version. The macOS version is signed ad hoc and not notarized by Apple; the README says how to open it the first time. Translations other than Simplified Chinese and English are machine-made; PRs that fix them are welcome.
