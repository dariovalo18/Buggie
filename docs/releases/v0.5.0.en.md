# Buggie v0.5.0

**Coo is now Buggie, a programming assistant for developers: build errors become bugs on the screen, teams share tickets, and you can talk to Buggie on Telegram**

## New

- **Buggie**: a new name, figure and mark. Buggie is an assistant that helps you read, write and debug code.
- **Errors become bugs**: run a build or tests with `buggie-watch -- <command>` and each error is a ladybug on the ground; click one and Buggie explains what went wrong and how to fix it. Buggie eats the bugs once they are fixed. Copy an error or a stack trace and Buggie asks whether to explain it.
- **GitHub**: when turned on, failed Actions steps become bugs too, and Buggie passes on new notifications on pull requests and issues.
- **Toolkit**: a hover button for the text on the clipboard: format JSON, Base64, JWT, timestamps, URL encoding, SHA-256, UUIDs.
- **Focus**: a hover button starts a focus block and reminds you to take a break when it ends.
- **Team server**: the Buggies of one company share the company, work groups, projects and tickets. Buggie tells you when a ticket is assigned to you, when a new one arrives in your work group, and when your tickets change or get a comment. When it opens a ticket, Buggie asks for the details still missing: what should happen, the steps, how to know it is fixed. Sign in on the **Team** page of the settings window; to run the server, see `team-server/README.md`.
- **Telegram**: link your own bot, or the company's bot on the team server, on the **Telegram** page of the settings window. What you write to Buggie there is an order: it does it and answers there. Choices and confirmations go there too; reply with the option's number. The company's bot can also send you ticket news while your Buggie is not connected.

## Download

- Windows x64 installer: `Buggie-Setup-0.5.0.exe`
- Windows x64 portable: `Buggie-0.5.0-win-x64-portable.zip`
- Apple silicon Mac: `Buggie-0.5.0-mac-arm64.dmg` / `.zip`
- Intel Mac: `Buggie-0.5.0-mac-x64.dmg` / `.zip`
- Linux x64: `Buggie-0.5.0-linux-x64.deb` / `.AppImage`
- `SHA256SUMS.txt`: SHA-256 checksums of the eight installer files.
- `latest.yml`, `latest-linux.yml`: version info for automatic updates; no need to download.

The Windows installer and the AppImage update themselves to later versions. The macOS version is signed ad hoc and not notarized by Apple; the README says how to open it the first time. Translations other than Simplified Chinese and English are machine-made; PRs that fix them are welcome.
